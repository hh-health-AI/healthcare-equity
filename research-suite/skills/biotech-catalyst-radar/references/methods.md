# Methodology

Date taxonomy: trial start; primary completion; study completion; data cutoff; sponsor-guided results announcement; conference release; filing; regulatory action. Never substitute one for another. Preserve year, quarter, month or day precision. Mark whether a registry date is estimated or actual.

Interpret enrollment, sites, design and endpoints with context. A change can reflect administrative housekeeping, delayed reporting, recruitment constraints or a protocol amendment; it is not proof of efficacy or failure. Financial implications are hypotheses requiring separate underwriting.

Monitoring state is atomic, scoped to a fixed set of IDs, and only advances after all requested records arrive and a report is written. Do not run concurrent jobs against the same state path. Preserve dated snapshots externally when a complete version history is required. Example cron/scheduler instructions are documentation only.
