# Methodology

Material ladder: title → abstract → poster/oral presentation → publication and supplement. Each step can add methods and revise earlier estimates. Keep separate dates for embargo lift, presentation, data cutoff and publication.

Evidence delta dimensions: enrollment/cohort, dose, follow-up, endpoint definition, evaluable population, response confirmation, censoring, safety denominator and discontinuations. Describe changes with original values and cited dates.

Patient overlap: match trial ID plus cohort identity, treatment, inclusion criteria, sites, enrollment dates and sample size. A new abstract number is not a new study. Do not pool or count repeated cohorts as corroboration. Public flags are supplied input; the agent must verify them at source, and the script only enforces the declared timestamps.
