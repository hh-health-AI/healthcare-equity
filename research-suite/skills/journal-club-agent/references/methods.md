# Methodology

Teaching checklist: explain allocation and estimand in plain language; interpret confidence intervals; separate statistical significance from clinical importance; show absolute effect where valid baseline risks exist; discuss external validity; inspect adverse-event denominator and exposure; give missingness and protocol deviations appropriate weight.

Eight-slide outline must remain balanced: devote space to limitations and harms, not only headline efficacy. Cite the exact figure/table or methods section on each relevant slide. Do not reproduce copyrighted figures without an appropriate basis; prefer newly created factual summaries with attribution.

Discussion questions should test reasoning, not trivia: what alternative explanation remains? which design decision matters most? how would applicability change in a different population? Human facilitators should verify all numbers before teaching.
