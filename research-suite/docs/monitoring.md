# Running a catalyst watchlist

The `watch` command performs one run and exits. Installation does not create scheduled jobs or notifications.

```bash
hh-research watch --ids NCT04280705 --state outputs/watch-state.json --out outputs/watch-report.md
```

Use a fixed list of unique NCT IDs. The initial state is a baseline, not a change report. Later runs require the same IDs, a complete fetch of every record and increasing timestamps. The report is written before state is advanced. Preserve reports and state copies with dates if you need a historical archive; the state path itself retains only the latest snapshot.

To change watchlist membership, choose a new state filename and establish a new baseline. Do not compare a partial search result to a complete historical snapshot. Do not run two jobs concurrently against the same state file.

To schedule it, use your existing scheduler after you choose a cadence and destination. For example, a local cron entry can call the environment's absolute `hh-research` path at a chosen time. Configure locking to prevent overlap, preserve stderr and exit status, and alert yourself on nonzero exit. No executable cron entry is installed by this package.

Registry completion estimates are not sponsor-announced readout dates. FDA decision dates, filings and conference events require separately verified sources and are research workflow tasks, not automatically generated by the registry watcher.
