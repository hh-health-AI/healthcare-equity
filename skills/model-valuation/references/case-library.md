# Case Library — 24 evidence-to-valuation patterns

Source mappings, periods, locators and verification scope are now public in the [source audit](case-source-audit.md) and [machine-readable ledger](case-sources.json). These are teaching patterns, not completed investment recommendations. All model mappings are hypotheses: apply CHANGE, NO_CHANGE, UNCERTAINTY_ONLY or NEEDS_DATA after checking the current model. Unverified numbers below must not be used as investment inputs.
